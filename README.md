💻 Computer Information Management System

A simple C++ project that stores and manages computer information using a Linked List.

🚀 Features

- Add computer name.
- Store IP Address.
- Store MAC Address.
- Save information in Linked List nodes.
- Display stored computer information.

🛠️ Technologies

- C++
- Struct
- Linked List
- Pointers
- Loops

🎯 Project Purpose

This project was created as a practical exercise to improve my C++ programming skills and understand how Linked Lists work.
